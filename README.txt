APLICACIÓN DE COLAS - SISTEMA DE TURNOS

Proyecto Java para administrar solicitudes del centro de soporte técnico universitario.

REQUISITOS
- Tener instalado Java JDK 17 o superior.
- Tener Visual Studio Code con el paquete de extensiones para Java.

OPCIONES DEL PROGRAMA
1. Registrar solicitud.
2. Consultar la siguiente solicitud sin retirarla.
3. Atender la primera solicitud.
4. Mostrar todas las solicitudes pendientes.
5. Consultar cuántas solicitudes están pendientes.
6. Comprobar si la cola está vacía.
0. Salir.
